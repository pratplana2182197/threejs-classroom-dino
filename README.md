# 🦖 DinoClassroom: The No-Internet Dinosaur Portal Game

Welcome to **DinoClassroom**, a WebGL-based simulation where a classroom full of students with no internet has one thing left to do: play the offline Dinosaur game. But there's a twist — you can walk up to a laptop or whiteboard and **enter** the game through a 3D portal, experiencing it from inside while the classroom keeps running in sync!

---

## 💡 Features

- First-person 3D navigation using `W`, `A`, `S`, `D` + mouse
- Realistic classroom environment with desks, laptops, lights, and shadows
- Interactive laptops and whiteboard that run the classic Dino game
- Press `E` near a laptop or screen to **enter** the Dino game through a portal
- Play the Dino game with `Space` or `Arrow Up` to jump, and `Arrow Down` to duck
- Toggle sunlight with key `N` and ceiling lights with key `L`
- Once inside the Dino game, a screen shows the live classroom view from the portal
- The Dino game state is preserved whether you are inside or outside the screen

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-user/dinoclassroom.git
   cd dinoclassroom
   ```

2. **Install dependencies** (requires [Node.js](https://nodejs.org/)):
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:5173
   ```

---

## 🎮 Gameplay Instructions

- Walk around using `W`, `A`, `S`, `D` keys
- Move the camera with the mouse
- Press `N` to toggle sunlight
- Press `L` to toggle ceiling lights
- Approach a laptop or whiteboard to see a prompt
- Press `E` to enter the Dino game via the portal
- Inside the Dino world:
  - `Space` or `Arrow Up` to jump
  - `Arrow Down` to duck
  - Look around freely — the game continues!
- A screen inside the Dino world shows the view from the classroom screen you entered through
- You can still toggle lights from inside the Dino game
